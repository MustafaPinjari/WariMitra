# iOS Device Fingerprinting Setup

This document explains how to configure the iOS native code for device fingerprinting on iOS using platform channels.

## Overview

The device fingerprinting service on iOS uses:
- **IDFV (Identifier for Vendor)**: A unique ID per vendor, vendor-scoped
- **Device Model**: e.g., "iPhone13,1"
- **System Version**: e.g., "17.2"

These components are combined with SHA256 hashing on the Dart side to produce a 64-character hex string.

## Files

### Dart Side (Already Implemented)
- `lib/services/device_fingerprint_service.dart`: Main service with iOS support
- `test/services/device_fingerprint_service_test.dart`: Tests including iOS cases

### Native iOS Side (To Be Configured)
- `ios/Runner/DeviceFingerprintChannel.swift`: Swift implementation for Keychain access

## Setup Instructions

### 1. Configure the Platform Channel

The Dart code expects a platform channel at `com.warimitra.device_fingerprint/channel`.

You need to set this up in your `ios/Runner/GeneratedPluginRegistrant.swift` or directly in your `ios/Runner/ViewController.swift`.

### 2. Add the Method Channel Handler

In your main Flutter ViewController (typically `ios/Runner/ViewController.swift`), add:

```swift
import UIKit
import Flutter

@UIApplicationMain
@objc class GeneratedPluginRegistrant: NSObject {
  @objc class func register(with registry: FlutterEngine) {
    // This method is auto-generated by Flutter
  }
}

class ViewController: FlutterViewController {
  override func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
  ) -> Bool {
    let controller = window?.rootViewController as! FlutterViewController
    let deviceFingerprintChannel = FlutterMethodChannel(
        name: "com.warimitra.device_fingerprint/channel",
        binaryMessenger: controller.binaryMessenger
    )
    
    deviceFingerprintChannel.setMethodCallHandler { (call: FlutterMethodCall, result: @escaping FlutterResult) in
        switch call.method {
        case "getIDFV":
            result(DeviceFingerprintChannel.getIDFV())
        case "getFingerprint":
            result(DeviceFingerprintChannel.getFingerprint())
        case "storeFingerprint":
            if let args = call.arguments as? [String: Any],
               let fingerprint = args["fingerprint"] as? String {
                let success = DeviceFingerprintChannel.storeFingerprint(fingerprint)
                result(success)
            } else {
                result(FlutterError(code: "INVALID_ARGS", message: "Missing fingerprint argument", details: nil))
            }
        case "clearFingerprint":
            let success = DeviceFingerprintChannel.clearFingerprint()
            result(success)
        default:
            result(FlutterMethodNotImplemented)
        }
    }
    
    GeneratedPluginRegistrant.register(with: self)
    return super.application(application, didFinishLaunchingWithOptions: launchOptions)
  }
}
```

### 3. Keychain Configuration

The Swift implementation uses the iOS Keychain for secure storage:

- **Service**: `com.warimitra.device_fingerprint`
- **Account**: `device_fingerprint`
- **Data**: The 64-character hex string fingerprint

Keychain provides:
- Encryption at rest
- Vendor-scoped storage (survives app uninstall/reinstall)
- Secure deletion

### 4. IDFV Behavior

**Important:** IDFV (Identifier for Vendor) is:
- Unique per vendor (app publisher) per device
- The same across all apps from the same vendor on the same device
- Remains the same if the user reinstalls the app
- Reset only when all apps from that vendor are uninstalled from the device

This means the fingerprint will survive app uninstall/reinstall on iOS (unlike Android).

The SOS service (`lib/services/sos_service.dart`) already integrates device fingerprinting:

```dart
final deviceFingerprint = await _fingerprintService.getFingerprint();

final requestBody = {
  'latitude': latitude,
  'longitude': longitude,
  'radius': radius,
  'device_fingerprint': deviceFingerprint,

```

## Troubleshooting

### "Platform channel not found" Error
- Ensure the method channel is set up in ViewController.swift
- Verify the channel name: `com.warimitra.device_fingerprint/channel`

### Keychain Access Issues
- Ensure the app has the correct entitlements for Keychain access
- Check `ios/Runner/Entitlements.plist` has `keychain-access-groups` if needed

### IDFV Returns nil
- IDFV might be unavailable in very rare cases (very old iOS versions)
- The code defaults to "unknown" in such cases
- This will result in a different fingerprint but won't crash

## Security Considerations

1. **Keychain**: Data is encrypted at rest by iOS
2. **IDFV**: Vendor-scoped, not user-identifiable alone
3. **Fingerprint**: Combined component hash (SHA256), not personally identifiable
4. **Transport**: Always send over HTTPS in SOS requests
